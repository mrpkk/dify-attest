# Privacy Policy — attest plugin

The plugin sends the artifact you pass and, optionally, the JSON Schema and your
entitlement token to the attest API endpoint you configure (by default
`https://attest.rta.lat`).

- No telemetry is collected by the plugin itself.
- The hosted service keeps aggregate counters (views, checks, paid calls) and an
  in-memory per-IP daily counter. Artifacts are not stored.
- If you self-host attest, no data leaves your infrastructure.
- Contact: github.com/mrpkk
